# API OS
Librairie qui gère des accès aux OS, leurs particularités.

# Comment l'utiliser ?
Utiliser la classe :
```java
import com.phenix.apios.OS;
```

Exemple :
```java
import com.phenix.apios.OS;

void main(String[] args) {
    // Valeur Windows pour un OS.
    OS.WINDOWS;

    // Retourne true si l'OS où est lancé le progragramme est Windows.
    OS.isWindows();
    // ...
}
```
